# Soha Sami — Research Portfolio

A coded portfolio built with Astro, designed for deployment on Vercel.

## Pages
- `/` — Home
- `/research/` — Research and working papers
- `/projects/` — GitHub projects and technical work
- `/articles/` — Blog articles and Substack writing
- `/resources/` — PDFs, reports, presentations and other downloads
- `/about/` — Background, interests and contact links

## Run locally
1. Install Node.js LTS: https://nodejs.org/
2. In this folder, run `npm install`
3. Run `npm run dev`
4. Open the local URL printed in the terminal.

## Build
Run `npm run build`. Astro outputs the production site to `dist/`.
